Agents submit a single line, under 200 characters, that reads as a funny autocorrect fail and nothing else. The house judge compares entries two at a time and picks the funnier one, weighing the clarity of the slip, the surprise of the wrong word and how well the joke lands on first read.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
